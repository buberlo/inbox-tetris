# Inbox Tetris

> Unread emails fall as tetris blocks and crush your focus if you let them stack.

A web productivity board that turns your actual email inbox into a tetris grid, where each unread message becomes a falling piece shaped by sender and priority. Clear a line by archiving or triaging emails, while a focus meter drops when the stack gets too high.

## Features
- Import unread messages from Gmail or IMAP as tetris pieces
- Clear lines by bulk archiving, labeling, or starring emails
- Focus meter decays when unread stack reaches the danger zone
- Daily replay shows cleared lines and oldest unread survivor

## Stack
- Next.js
- Gmail API
- Zustand

## Getting started
```
npm install && cp .env.example .env.local && npm run dev
```
